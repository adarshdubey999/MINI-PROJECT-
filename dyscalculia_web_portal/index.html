🎯 Evidence-Based Educational Guidance

  • Multi-Sensory Manipulatives: Implement Numicon tiles, base-10 blocks, and Cuisenaire rods to make quantitative grouping concrete.
  • Visual Desk Number Strip: Provide 0-100 number line ruler to scaffold calculations without counting fingers.
  • Extended Testing Time: Provide 30% extended time on arithmetic tasks to accommodate retrieval delays.
  • Permitted Four-Function Calculator: Allow calculator usage for reasoning tasks so calculation blocks don't hinder problem comprehension.
